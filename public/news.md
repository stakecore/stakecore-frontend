# News

Human URL: <https://stakecore.org/#/news>

What we have shipped, and what has changed on the networks we run. Newest
first.

## What lands here

Three kinds of post. **Release** — software StakeCore has built and published.
**Network** — a change on one of the networks it runs, such as a client
upgrade or a protocol change. **Incident** — something that went wrong, and
what was done about it. Every post is listed on this page, newest first.

## FAsset Visualiser

2026-08-20 · Release

A live system view of Flare's FAsset protocol. Each FAsset — FXRP, FBTC,
FDOGE — is drawn as a tunnel whose width is its total backing capacity, split
between minted backing and free capacity, with the agents behind it coloured
by status and every mint and redemption flowing through as it happens. A
second deployment runs the same view against the Coston2 test network.

- Flare: <https://fasset.stakecore.org>
- Coston2 testnet: <https://fasset-coston2.stakecore.org>

Both are client-rendered applications with no markdown mirror and no public
API — there is nothing there for an agent to read.
